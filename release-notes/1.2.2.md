## What's new in 1.2.2

**Cipher Pact**
- New 🟥 **Color boxes** style: every letter of the secret becomes a coloured box (🟥🟦🟢💛…). These messages get their own `BOX-` key, so the key card, the wheel, Practice and Read all use the boxes.
- New 😀 **Emoji letters** style: the same, letter by letter, with everyday emoji (🍕🦊🚀…) and `EMO-` keys.
- The old Emoji words style (one emoji per word) is no longer offered; messages made with it still read back.
- Emoji you type in a secret now come back exactly, also with emoji alphabets (🍕 used to turn into a letter) and in the 🔑 Clues style (❤️ used to lose its colour).
- Read mode finds the right key even when the note holds emoji, another script or a name in another alphabet.
- The AI note no longer invents fake codes or instructions ("key 'X'", "count the odd numbers"…), and rambling notes are trimmed.
- Emoji with skin tones and colours show correctly in sealed messages; key cards for Word swap and Number map messages are gone (their key is the message itself).

**Other modules**
- Esoteric Languages: Befunge could not compile some text (a ❤️ gave "Cannot build 239").
- Dingbats: ❤️ and other emoji with a colour selector now come back exactly.
- Braille on phones: in the AI modes the title no longer runs into the Clear button and the AI badges no longer overlap the tab labels; the intro shock wave no longer leaves an oversized invisible ring behind.

**For developers**
- `npm run check -- <module|all>` tests a module on desktop and on emulated phones and tablets: static rules, exact round trips, layout, every button, leaks and errors.
