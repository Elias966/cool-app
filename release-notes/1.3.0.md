## What's new in 1.3.0

**Universal translator on Home**
- A new bar at the top of Home reads anything any module made, without opening the module or knowing which one it was: braille, Base64, Wingdings and the other dingbat fonts, runes, hieroglyphs and the other ancient scripts, Brainfuck and the other esoteric languages, layered encodings, all five Japanese styles, and Cipher Pact messages.
- It names the module and style, shows how sure it is (✓ exact when the text carries Prism's invisible copy), lists other possible readings, and opens the module in one tap.
- Sealed Cipher Pact messages are read with the keys in your key ring; when the key is missing it says so.
- Works the same on desktop, phones and tablets.

**Fixes**
- Cipher Pact's Read mode no longer "reads" text made by other modules.
